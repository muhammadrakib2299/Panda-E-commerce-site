# Panda E-commerce

A storefront landing page for an e-commerce shop, built with HTML and Bootstrap.

**Live demo:** https://muhammadrakib2299.github.io/Panda-E-commerce-site/

## Sections / Features

- A fixed-top Bootstrap navbar with in-page links to the Shoes, Backpack and Subscribe sections
- A Bootstrap carousel banner with three slides (headphones, LCD TV, Xbox) and prev/next controls
- Category tiles for Watch, Bag and Shoes
- Product card grids for shoes and backpacks, each card with a price and a Buy Now button
- A "Let's Stay in Touch" email subscribe block and a footer

## Built with

HTML5 · Bootstrap 5.0.2 (CSS and JS bundle via CDN), styled with Bootstrap utility classes

## What I practised

- Bootstrap's carousel and navbar components
- Responsive card grids (`row-cols-*`, `col-md-6 col-lg-4`)
- Anchor navigation to section IDs

## Run locally

Open `index.html` in a browser.
